## 🚀 How to Deploy on GitHub Pages (Step-by-Step)

### Step 1 — Create a GitHub Account
Go to [github.com](https://github.com) and sign up (if you haven't).

### Step 2 — Create a New Repository
1. Click the **+** icon → **New repository**
2. Name it: `your-username.github.io` (replace with your actual GitHub username)
   - Example: `lamarajkumar.github.io`
3. Set it to **Public**
4. Check **"Add a README file"**
5. Click **Create repository**

### Step 3 — Upload Your Files
1. Inside your new repo, click **"Add file"** → **"Upload files"**
2. Drag and drop all 4 files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Scroll down, write a commit message like `"Add portfolio website"`
4. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to your repo → **Settings** tab
2. Scroll down to **"Pages"** (left sidebar)
3. Under **Source**, select `Deploy from a branch`
4. Set Branch to `main` and folder to `/ (root)`
5. Click **Save**

### Step 5 — Visit Your Website 🎉
Wait 1–2 minutes, then visit:
```
https://your-username.github.io
```
